# برنامهٔ آغاز مرحلهٔ ۸.۳ (بخش اول): صفحه‌های اصلی فروشگاه سایت

> **وضعیت:** پیش‌نویس، در انتظار بررسی مالک محصول.
> **پایه:** برنامهٔ آغاز فاز ۸ (`V11_STOREFRONT_START_PLAN.md`، تصمیم‌های ۱ و ۲) و Storefront API مرحلهٔ ۸.۱ (PR #445).
> **اصل:** کیفیت پیش از زمان؛ این برنامه تاریخ ندارد. هر بخش با تأیید مالک روی پیش‌نمایش تمام می‌شود.

## ۱. چه ساخته می‌شود
برنامهٔ فروشگاه (SSR) در پوشهٔ `storefront/` با React Router 7 و Tailwind 4 (تأییدشده در تصمیم ۲). سه صفحه و پوستهٔ مشترک:

- **پوسته:** سرصفحه با نشان، کالکشن‌ها و جست‌وجو؛ پاصفحه با راه‌های تماس، اینستاگرام و واتس‌اپ. راست‌به‌چپ، قلم وزیرمتن از همان فایل‌های خود ERP، اعداد فارسی، مبلغ به تومان.
- **صفحهٔ اصلی:** تصویر و پیام اصلی، کالکشن‌ها، پرفروش‌ها یا تازه‌ها، و بخش «هدیهٔ سازمانی و خرید عمده» که فعلاً به تماس می‌رسد.
- **صفحهٔ کالکشن و همهٔ محصولات:** فیلتر کالکشن و دسته، مرتب‌سازی، صفحه‌بندی روی سرور. هر کارت قیمت و وضعیت موجودی را روشن نشان می‌دهد (یافتهٔ بررسی اینستاگرام).
- **صفحهٔ محصول:** گالری تصویر، قیمت درشت و روشن، موجودی بنا به تنظیمات، جنس، اندازه، رنگ و وزن، توضیح، کالاهای هم‌کالکشن، و نشانی کوتاه برای پست اینستاگرام.

## ۲. مرزها
- فقط پنج مسیر خواندنی API مرحلهٔ ۸.۱ خوانده می‌شود. کلید API فقط روی سرور برنامهٔ فروشگاه است و هرگز به مرورگر نمی‌رسد؛ تصویرها از راه همان سرور داده می‌شوند.
- قیمت عمده هیچ‌جا نمایش داده نمی‌شود (در API عمومی هم نیست).
- **سبد و تسویه در این بخش نیست** و پس از ۸.۲ می‌آید. تا آن زمان دکمهٔ «افزودن به سبد» ساخته نمی‌شود؛ جای آن دکمهٔ «سفارش در واتس‌اپ» است (اگر مالک بخواهد).
- برنامهٔ ERP عوض نمی‌شود. فروشگاه تا وقتی `sf_enabled` خاموش است چیزی نشان نمی‌دهد، و سرویس آن در این مرحله نصب نمی‌شود (نصب در ۸.۶).

## ۳. پیش‌نمایش و دادهٔ واقعی
- پیش‌نمایش روی سرور مالک اجرا نمی‌شود. صفحه‌ها روی محیط خودمان ساخته و به‌صورت یک صفحهٔ خصوصی (Artifact) با پیوند پیش‌نمایش داده می‌شوند، همراه اسکرین‌شات گوشی و دسکتاپ.
- دادهٔ پیش‌نمایش یک API نمونه با همان قرارداد `storefrontContracts.ts` است. تا محصولات در ERP منتشر شوند، نام‌ها و عکس‌ها از محصولات واقعی همین برند (سایت خارجی) می‌آیند و قیمت‌ها نمونه‌اند. وقتی محصولات در ERP منتشر شدند، خروجی همان API جایگزین می‌شود.
- دادهٔ نمونه و عکس‌ها در مخزن عمومی گذاشته نمی‌شوند؛ مخزن فقط چند ردیف ساختگی برای آزمون دارد.

## ۴. معیار تمام شدن این بخش
- تأیید مالک روی پیش‌نمایش گوشی و دسکتاپ، از جمله مرورگر درون اینستاگرام.
- LCP زیر ۲٫۵ ثانیه روی گوشی میانه در آزمون آزمایشگاهی؛ اندازه‌گیری از ایران در ۸.۶.
- آزمون‌ها: قرارداد داده، نبود قیمت عمده و کلید در HTML، کار بدون JavaScript برای فهرست و محصول، و دسترس‌پذیری پایه.
- یک خط در «### Unreleased» و `npm run release:renumber`؛ هیچ ادغامی بدون گفتهٔ مالک.

## ۵. پرسش از مالک محصول
1. **متن کالکشن‌ها:** متن‌های سایت فعلی از بیرون ایران خوانده نمی‌شوند. مالک متن‌ها را می‌فرستد، یا با یک کار کوتاه روی رایانهٔ مالک خوانده شوند؟
2. **سفارش در واتس‌اپ** تا آمدن سبد: بله یا نه؟
3. **دادهٔ پیش‌نمایش:** عکس‌ها و نام‌های سایت خارجی با قیمت نمونه، تا محصولات در ERP منتشر شوند؟
